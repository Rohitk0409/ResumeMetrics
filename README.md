# ResumeMetrix

AI Powered ATS Resume Ranking Platform

## Features

- ATS Score Analysis
- Resume Ranking
- Job Description Matching
- PDF Resume Parsing
- Multi Resume Upload
- Recruiter Dashboard

## Tech Stack

### Frontend

- React
- Vite
- Tailwind CSS
- TanStack Query

### Backend

- Node.js
- Express.js
- MongoDB
- Multer
- PDF Parse

## Installation

### Frontend

cd ATS_Frontend

See ATS_Frontend/README.md

### Backend

cd ATS_Backend

See ATS_Backend/README.md

## Architecture

Frontend → Express API → ATS Engine → Ranking System
